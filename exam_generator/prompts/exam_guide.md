# 시험 유형별 AI 문제 제작 지침

이 문서는 의과대학 시험 대비 **AI 문제 세트 생성** 시 적용할 표준 지침을 정리한 것이다.

<aside>
⚠️

**핵심 원칙**: 모든 문제는 반드시 **해당 강의 전사본에 언급된 내용만**을 범위로 한다. 교과서·외부 자료·AI의 일반 지식으로 범위를 벗어나지 않는다. 기존에 만들어진 문제 세트는 참고하지 않는다 (별도 지시가 없는 한).

</aside>, 답이 non-obvious하게 제작해야 함에 반드시 주의 객관식이든 주관식이든,

가나다라형 빼고는 선지 다 원문자로!!

# I. 문제 유형

## 유형 A: 오지선다 "모두 고르시오"

가장 주력으로 사용하는 유형이다.

| **항목** | **규격** |
| --- | --- |
| 선지 수 | 5개 — 원문자 1~5|
| 정답 개수 | 1~5개 (균등 분포) |
| 문항 수 | 기본 40문항 (조정 가능) |
| 지시문 | "다음 중 옳은 것을 **모두** 고르시오." |

## 유형 B: "모두 적으시오" (서술/단답형)

심장생리 출제 교수의 실제 시험 형식을 참고한 유형이다.

| **항목** | **규격** |
| --- | --- |
| 형식 | 임상 시나리오 제시 → 여러 파라미터를 나열 → 각각 **증가 / 정상 / 감소** 기입 |
| 문항 수 | 기본 5문항 (조정 가능) |
| 파라미터 수 | 문항당 5~8개 |
| 난이도 | 오지선다보다 높게 — 기전 연쇄를 통째로 추론해야 답을 쓸 수 있도록 |

## 유형 C: 단답형 문제

오지선다 세트의 보충으로 사용하는 단답형 유형이다. **3가지 하위유형**으로 구성하며, 기본 13문항(오지선다 40문항 보충 시)이다.

### C-1: 단순 용어형 (~7문항)

| **항목** | **규격** |
| --- | --- |
| 형식 | **S + 발문** → 토글(정답) — 선지 없음, 한 단어~한 줄로 답 |
| 정답 길이 | **1단어~1줄** — 인자명, 질병명, 수용체, 효소, 과학자 이름 등 |
| 문항 스타일 | "~의 이름은?", "~을/를 무엇이라 하는가?", "빈칸에 들어갈 단어는?", "~하는 물질은?" |
- **한 문항 = 한 개념**: 여러 개념을 섞지 않는다
- 정답이 **고유명사·전문 용어**가 되도록 발문을 설계
- 교수가 강조(🎯)한 내용 우선 출제
- 비교형 문항 활용: "siRNA와 miRNA 중 완전한 상보결합을 형성하는 것은?"

### C-2: 약술형 (~3문항) - 요청할 경우 제외하고 출제하지 않음

| **항목** | **규격** |
| --- | --- |
| 형식 | **S + 발문** → 토글(정답) — 2~4줄의 기전 서술로 답 |
| 정답 길이 | **2~4줄** — 기전·원리를 간결하게 서술 |
| 핵심 원칙 | **발문에 기전·경로 힌트를 주지 않는다** — 객관식처럼 "왜 ~한가?", "~의 이유를 설명하시오" 형태로만 출제 |
- 발문은 **현상만 제시**하고, 학생이 기전을 스스로 떠올려야 정답을 쓸 수 있도록 설계
- **금지**: "A → B → C의 흐름으로 설명하시오", "~을/를 ~의 관점에서 설명하시오" 등 기전 유도형 발문
- 예시 비교:
    - ✅ "매운 음식을 먹으면 얼굴에 땀이 나는 이유를 설명하시오."
    - ❌ "TRPV1 → 뇌 → 발한의 흐름으로 설명하시오."

### C-3: 모두 적으시오 (~3문항)

| **항목** | **규격** |
| --- | --- |
| 형식 | **S + 발문** → 토글(정답) — 해당 항목을 빠짐없이 나열 |
| 정답 | **3개 이상의 항목** — 단순 나열 또는 항목+속성 쌍으로 답 |
| 문항 스타일 | "~을/를 모두 적으시오.", "~을/를 모두 적고 각각의 ~을/를 쓰시오." |
- 전사본에 언급된 항목을 빠짐없이 나열하는 것이 핵심
- 항목 + 속성 쌍 문항 활용: "TRP 채널을 모두 적고 각각의 활성화 온도를 쓰시오"
- 순서 나열형도 가능: "~의 단계를 순서대로 모두 쓰시오"

### 단답형 토글 구조

→ **IV. 토글 구조 총정리** 참조

### 단답형이 오지선다와 혼합될 때

- 오지선다 문항 뒤에 **S1, S2, S3…** 번호로 단답형을 배치
- 배치 순서: **C-1(용어형) → C-2(약술형) → C-3(모두 적으시오)**
- 예: "문제 세트 (40문항 + 단답 13문항)" → Q1~Q40 = 오지선다, S1~S7 = 용어형, S8~S10 = 약술형, S11~S13 = 모두 적으시오
- 정답표에는 단답형도 포함하되 정답만 간결하게 기재

---

## 유형 D: 혼합 세트 (오지선다 + 적으시오)

유형 A + 유형 B를 하나의 문제 세트로 합친 형태.

- 기본 구성: **오지선다 40문항 + 적으시오 5문항 = 45문항**
- 단답형을 추가할 수도 있음: **오지선다 40문항 + 단답 13문항 = 53문항**
- 교수가 "심장생리보다 어렵게" 등 난이도 예고를 한 경우 반영

# II. 정답 분포 규칙

<aside>
🎲

**정답 개수 분포**: 40문항 기준 각 정답 개수(1개, 2개, 3개, 4개, 5개)가 **8문항씩** 균등 배분되어야 한다.

</aside>

## 흔한 실수 — 반드시 회피할 것

| **문제점** | **설명** | **해결책** |
| --- | --- | --- |
| 정답 개수 편중 | AI가 정답을 2~3개로 몰아주는 경향 | 정답 개수별 문항 번호를 사전에 배정표로 확정한 뒤 작성 |
| 순차적 정답 패턴 | 정답이 (가,나) / (가,나,다) / (가,나,다,라) 식으로 누적 | 정답 선지 조합을 **랜덤**으로 배치 — 예: 정답 2개일 때 (가,마), (나,라) 등 |
| 섹션별 정답 군집 | Case 1 문제는 정답 1개, Case 2 문제는 정답 3개 식으로 묶임 | 정답 개수를 문항 번호 순으로 **인터리빙** — 연속 2문항 이상 같은 정답 개수 지양 |

### 배정표 예시 (40문항)

```
정답 1개: Q3, Q7, Q11, Q16, Q21, Q26, Q31, Q36
정답 2개: Q1, Q6, Q12, Q17, Q22, Q27, Q32, Q37
정답 3개: Q2, Q8, Q13, Q18, Q23, Q28, Q33, Q38
정답 4개: Q5, Q9, Q14, Q19, Q24, Q29, Q34, Q39
정답 5개: Q4, Q10, Q15, Q20, Q25, Q30, Q35, Q40
```

# III. 선지 작성 원칙

## 1. 간결하되 헷갈리게

- 선지는 **1~2문장의 문장형**으로 작성
- 지나치게 긴 선지 금지 — 길이 자체가 정답 단서가 됨
- 정답 선지와 오답 선지의 **평균 길이가 비슷**해야 함

## 2. 단순 선지 문항도 반드시 포함

- 모든 선지가 문장형일 필요는 없다. **인자명, 질병명, 수용체, 호르몬, 효소** 등 **한두 단어짜리 단순 선지**로 구성된 문항도 일정 비율 포함한다.
- 예시:
    - "다음 중 T helper cell이 분비하는 cytokine을 모두 고르시오." → (가) IL-2 (나) TNF-α (다) IFN-γ (라) IL-10 (마) TGF-β
    - "다음 중 autosomal dominant 유전 질환을 모두 고르시오." → (가) Marfan (나) PKU (다) Huntington (라) CF (마) Achondroplasia
    - "다음 중 Gq protein-coupled receptor를 사용하는 호르몬을 모두 고르시오." → (가) GnRH (나) TRH (다) TSH (라) Oxytocin (마) GHRH
- 40문항 기준 **최소 8~10문항**은 이러한 단순 선지 문항으로 배치
- 단순 선지 문항에서도 함정은 동일하게 적용 — 유사 개념(예: IL-4 vs IL-14, Marfan vs Ehlers-Danlos)을 오답으로 섞어 혼동 유도

## 2. 선지에서 답 추론 차단

<aside>
🚫

다음 상황을 반드시 회피한다:

- 정답 선지만 유독 길거나 구체적인 경우
- 선지끼리 비교하면 기전이 암시되는 경우 (예: A선지에 "X가 증가"라 했는데 B선지에 "X 증가로 인해 Y가 감소"라고 써서 A가 맞음을 알려주는 구조)
- 정답끼리 논리적 연쇄가 보이는 경우 (하나가 맞으면 나머지도 자동으로 맞는 구조)
- 오답이 너무 터무니없어서 소거법으로 정답이 드러나는 경우
</aside>

## 3. 함정(트랩) 설계

| **함정 유형** | **예시** |
| --- | --- |
| 주어 바꿔치기 | "간에서 생산된 IGF-1이 직접 뼈 성장을 촉진한다" (실제는 local IGF-1) |
| 방향 반전 | "ACEi는 수입세동맥을 확장한다" (실제는 수출세동맥) |
| 인과 혼동 | "TSH가 높으므로 Graves' disease이다" (실제로 Graves'에서 TSH는 억제됨) |
| 유사 개념 치환 | "T3 resin uptake가 높으면 TBG가 증가한 것이다" (실제는 TBG 감소/T4 과잉) |
| 조건부 진실 | "GH를 투여하면 모든 소아의 키가 증가한다" (정상 소아에게는 효과 없음) |
| 부분적 오류 삽입 | 전체 문장은 맞아 보이지만 한 단어(수용체 이름, 효소 이름 등)만 틀림 |

## 4. 중간 수정 과정 비노출 (출력 전 확정 원칙)

<aside>
🚫

**정답 개수 배정표와 선지 내용이 충돌할 경우, 반드시 출력 전에 선지를 수정하여 정답 개수를 맞춘 뒤 최종 결과만 출력한다.**

- ❌ 금지: 해설에 "정답 3개? 아님", "수정 적용:", "재확인:", "선지 조정 필요", "정답 N개 배정이므로 조정", "이 선지도 사실 맞으나 정답 N개 유지 필요" 등 중간 사고 과정을 남기는 것
- ❌ 금지: 원래 선지 텍스트를 그대로 두고 해설에서 "선지 (나) 수정: ..." 형태로 수정 내용만 기술하는 것 — **선지 자체를 직접 수정**해야 함
- ✅ 올바른 절차: ① 선지 초안 작성 → ② 정답 개수 검증 → ③ 충돌 시 **선지 텍스트 직접 수정** → ④ 최종 확정된 선지와 깨끗한 해설만 출력
- ✅ 해설에는 각 선지의 정오 판정과 근거만 간결하게 기재
</aside>

# IV. 페이지 형식 및 레이아웃

## 토글 구조 총정리

<aside>
💡

모든 유형의 토글 형식을 여기에서 통합 관리한다.

</aside>

### 유형 A · B · D — 이중 토글 (오지선다 · 적으시오 · 혼합)

정답이 토글을 펼쳤을 때 바로 보이지 않도록 **이중 토글**을 사용한다.

#### 구조

```
바깥 토글: **문제 N.** [발문]
  ├─ 원문자 1 선지 1
  ├─ 원문자 2 선지 2
  ├─ 원문자 3 선지 3
  ├─ 원문자 4 선지 4
  ├─ 원문자 5 선지 5
  └─ 안쪽 토글: **정답 확인**
       └─ ✅ 정답: (X), (Y)
          해설 (전사본 근거 포함)
```

#### Notion 마크다운 예시

```
<details>
<summary>**문제 1.** 다음 중 옳은 것을 모두 고르시오.</summary>
	원문자 1 선지 내용 1
	원문자 2 선지 내용 2
	원문자 3 선지 내용 3
	원문자 4 선지 내용 4
	원문자 5 선지 내용 5
	<details>
	<summary>**정답 확인**</summary>
		✅ **정답:원문자 1, 원문자 3**
		해설 내용...
	</details>
</details>
```

#### 적으시오 변형

```
<details>
<summary>**문제 41.** [임상 시나리오]에서 다음 파라미터의 변화를 적으시오.</summary>
	| 파라미터 | 변화 (증가/정상/감소) |
	|---|---|
	| A |  |
	| B |  |
	...
	<details>
	<summary>**정답 확인**</summary>
		정답 테이블 + 해설
	</details>
</details>
```

### 유형 C — 단일 토글 (단답형)

선지가 없으므로 발문만 보고 답을 떠올린 뒤 토글을 여는 구조. **이중 토글 불필요**.

```jsx
**Q1.** RNA가 DNA보다 구조적으로 불안정한 원인이 되는 ribose의 작용기는?
<details>
<summary>정답</summary>
	2'-OH
</details>
```

- 발문이 토글 **바깥**에 위치
- 토글 `<summary>`: "정답"
- 정답 + 간결한 해설이 토글 안에 위치

### 황세진 교수 — 단일 토글 (가변 선지 + 단답형)

선지 번호가 ①②③… 으로 가변적이며, 발문과 선지가 모두 토글 **바깥**에 노출. **이중 토글 불필요**.

#### 모두 고르시오

```jsx
**Q12.** 다음 중 **C fiber**의 기능/특성을 **모두 고르시오.** ⭐ *기출 반복*
① 무수초 ② 전도속도 가장 느림 ③ 둔한 통증(second pain) 전달
④ Postganglionic autonomic fiber ⑤ Preganglionic autonomic fiber
⑥ 직경 가장 가늘다 ⑦ 가려움(itch) 전달 ⑧ 뜨거움(heat) 전달
<details>
<summary>정답</summary>
	**①②③④⑥⑦⑧**
	- ⑤ Preganglionic autonomic → **B fiber** (유수초)
</details>
```

#### 단답형

```jsx
**Q36.** DRG의 기능 추적에 사용되는 물질과 결합하는 motor protein을 쓰시오.
<details>
<summary>정답</summary>
	**Cholera toxin B**, **dynein**에 결합 (역방향 transport)
</details>
```

- 정답은 **굵은 글씨**로 표시
- 오답 선지만 `→` 기호로 올바른 답 안내

## 정답표

- 문제 세트 **맨 하단**에 전체 정답표를 테이블로 배치
- 토글 안에 넣어 스크롤 시 우발 노출 방지

# V. 소스 자료 활용 규칙

| **규칙** | **설명** |
| --- | --- |
| 전사본 Only | 해당 주제의 전사본 페이지에 **언급된 내용만** 출제 범위. 교과서 확장 금지. |
| 기존 문제 세트 무시 | 같은 주제의 기존 문제 세트를 참고하여 중복/유사 문항을 만들지 않음 (별도 지시 시 제외) |
| 형식 참고 페이지 | 교수의 실제 출제 형식 (예: 심장생리 출제문항)은 **형식과 난이도 감각**만 참고하고, 내용은 전사본에서 가져옴 |
| 강의록/정리노트 | 강의록은 전사본과 교차 검증 용도로만 사용. 강의록에만 있고 전사본에 없는 내용은 출제하지 않음. |

# VI. 난이도 조절 가이드

## 기본 난이도 (표준)

- 전사본에서 직접 언급된 사실을 정확히 기억하는지 확인
- 함정은 주어 바꿔치기, 방향 반전 수준

## 높은 난이도 (교수 예고 시)

- **2단계 이상 추론** 필요: 기전 A → 결과 B → 임상 소견 C
- 여러 Case의 개념을 **교차 비교**하는 선지
- "적으시오" 유형에서 파라미터 수 증가 (8개 이상)
- 유사 질환 간 감별 포인트를 묻는 문항 추가

## 문항 주제 분배

- 전사본에 등장하는 Case/주제별로 **균등 배분**
- 예: 전사본에 Case 4개 → 각 Case당 약 10문항씩 (40문항 기준)
- 한 Case에 문항이 몰리지 않도록 주의

## 케이스 기반 문항 포함 원칙

<aside>
🏥

**강의 전사본에 임상 케이스(Case)가 포함되어 있다면, 해당 케이스를 활용한 케이스 기반 문항을 반드시 출제 세트에 포함한다.**

</aside>

- **케이스 기반 문항**이란: 임상 시나리오(환자 정보·검사 소견·약물력 등)를 제시하고, 기전·감별·치료 원칙을 통합적으로 묻는 문항
- 강의에서 다룬 케이스를 그대로 활용하거나, 범위 내 개념을 **새로운 임상 시나리오**로 재구성하여 출제할 수 있다
- 케이스 문항은 기존 오지선다("모두 고르시오") 형식을 따르되, 발문 앞에 **임상 시나리오 블록**을 배치한다
- 문항 번호는 **C1, C2, C3…** 으로 별도 부여하고, 오지선다·단답형 뒤에 독립 섹션으로 배치한다
- 정답 개수 분포는 오지선다와 동일하게 **1~5개 균등 분포**를 지향한다
- 10문항 내외를 기본으로 하되, 케이스 수와 범위에 따라 조정 가능
- 하나의 케이스에서 여러 각도(기전·감별·치료)의 문항을 출제할 수 있으나, 동일 케이스에 문항이 과도하게 몰리지 않도록 분배한다
- 강의에 케이스가 **없는 경우**에는 케이스 문항을 생략한다 (무리하게 생성하지 않음)

## 문항 주제 범위의 다양성

<aside>
💡

하나의 작은 소주제만 다루는 문항에 치우치지 말고, **소주제 문항 · 종합 문항 · 응용 문항을 골고루 섞어** 균형 잡힌 세트를 구성한다.

</aside>

- **소주제 문항**: 개별 세부 개념을 정확히 아는지 확인하는 문항 (세트의 기본 구성)
- **종합 문항**: 여러 Case/섹션의 개념을 하나의 발문·선지에 교차 배치하여, 전체 흐름을 이해해야 풀 수 있는 문항 — 예: "말초 감작과 중추 감작의 공통 매개물질을 모두 고르시오"
- **응용 문항**: 2~3개 소주제를 가로지르거나, 기전을 새로운 상황에 적용해야 하는 문항 — 예: "Gate control theory와 하행성 억제계가 모두 관여하는 기전은?"
- 40문항 기준 종합·응용 문항을 **최소 6~8문항** 이상 배치하되, 나머지는 소주제 문항으로 채움
- 단답형(유형 C)에서도 소주제 간 비교·연결을 묻는 문항을 적절히 포함할 것

## 순서형 문항 포함 원칙

<aside>
⏳

**주제에 시간적·논리적 순서가 존재하는 경우, "가장 먼저 일어나는 것은?" / "순서대로 나열한 것은?" 등 순서형 문항을 반드시 포함한다.**

</aside>

- **순서형 문항**이란: 과정·단계·사건의 **시간적 선후 관계**를 묻는 문항
- 출제 형태 예시:
    - "~과정에서 가장 먼저 일어나는 것은?" (오지선다)
    - "~의 순서대로 올바르게 나열한 것은?" (오지선다)
    - "~의 단계를 순서대로 쓰시오" (단답형 C-3)
- **적용 대상**: 발생·발달, 신호전달 경로, 대사 과정, 면역세포 성숙, 병태생리 진행 등 **시간적 순서가 의미 있는** 모든 주제
- **제외 대상**: 해부학(구조 나열), 분류(taxonomy) 등 시간적 순서가 본질적으로 **의미 없는** 주제에서는 무리하게 순서 문항을 만들지 않음
- 함정 설계: 순서를 **뒤바꾸기**, 앞뒤 단계를 **혼동 유도**, 관련 없는 단계를 선지에 **끼워넣기**
- 40문항 기준 **최소 3~5문항** 이상 포함 권장

## 1. 선지 표기

<aside>
⚠️

황세진 교수 문제에서는 **(가), (나), (다), (라), (마)**가 아닌 **① ② ③ ④ ⑤ ⑥ …** (원문자 번호)를 사용한다. 선지 수가 **5개로 고정되지 않고 가변적**(5~10개 이상)이다.

</aside>

## 2. 핵심 출제 특징

| **특징** | **설명 및 예시** |
| --- | --- |
| 강의 일화 기반 단답형 | 교수가 수업 중 "대충" 언급하거나 일화로 풀어 설명한 내용을 단답형으로 출제 — 예: "밥 먹고 졸린 이유와 관련된 혈관은?", "DRG 기능 추적에 사용되는 물질과 결합하는 motor protein은?", "systemic vein이자 portal vein인 정맥은?" |
| 강의 확장·대충 언급 → 모두 고르시오 | 강의에서 살짝 확장하거나 "이건 꼭 알아두세요" 식으로 대충 넘어간 내용을 **선지 다수의 모두 고르시오**로 출제 — 예: "C fiber의 기능/특성을 모두 고르시오", "Cholera toxin B와 axonal transport", "avascular tissue 모두 고르시오" |
| 가변 선지 수 | 선지가 5~10개 이상으로 가변적 — 예: Golgi type I neuron 해당하는 것 10개 중 고르기, Neural Tube 유래 9개 중 고르기 |
| 바꿔치기 함정 | 유사 개념의 속성을 서로 뒤바꿔 출제 — 예: kinesin↔dynein, Schwann↔Oligodendrocyte, Aδ↔C fiber, radial↔ulnar, 전방↔후방 |
| "예외" 강조 | 일반 규칙의 예외를 집중 출제 — 예: "Microglia만 중배엽 기원", "Purkinje cell은 억제성이지만 Golgi type I", "B fiber는 preganglionic (C가 아님)", "intercostal a. 위 2쌍만 subclavian 기원" |
| 강의 원문 인용 | 교수의 원래 표현을 해설에 그대로 인용 — 예: "복부의 경찰관", "carotid a.를 안 쓰는 이유? 응고가 일어날 경우…" |

## 4. 문제 세트 구성

| **항목** | **규격** |
| --- | --- |
| 구조 | **섹션별 분리**: 모두 고르시오 → 주관식/단답형 순서로, 주제(챕터)별 섹션 구분 |

| 정답표 | **없음** — 각 문항의 토글에서 바로 확인하는 방식 |
| O 표시 | 선택적으로 문항 끝에 **O** 표시 (정답 개수가 많을 때) — 자기 채점 참고용 |

## 5. 해설 작성 원칙

- **간결함이 핵심**: 오답 선지만 `- ⑤ X → Y` 형태로 한 줄 설명
- 정답 선지가 많을 때 일일이 해설하지 않음 — 오답만 짧게
- 모든 선지가 정답일 때: "모두 맞음" + 핵심 포인트 한 줄
- 필요 시 강의 원문을 따옴표로 인용
- "핵심:", "함정:", "암기법:" 등 라벨을 붙여 학습 포인트를 강조
